# 需求变更 · 系统与数据模型定稿

## 一、背景

MVP 已跑通"生图工作台 + 多渠道 + 商品链接导入"，但四场讨论一致发现：**生成能力没有和商品、素材、成本、审计连成一条链**。

具体表现：

- 商品只存在原型 localStorage，素材与任务无法归属到 SKU；
- `asset` 一行一个文件，无法表达"主图的 v1/v2/当前交付版"；
- 删任务即物理删素材，与"原图不可再生、版本可回滚"冲突；
- 字段确认是"全有全无"阻断，会卡死 H3（30 分钟交付）；
- `provider_call.amount` 全为空，H2（单 SKU ≤ ¥15）无法取证；
- 没有登录与真实 `audit_log`，合规留痕没有"操作人"。

四场讨论分别给出了推荐方案，本次按"全选 B"定稿。

## 二、变更点

| # | 原内容 | 新内容 |
|---|---|---|
| 1 | `asset` 一行一个文件（TD-001 原设计） | **槽位 + 版本**：`asset` = SKU×用途×渠道×尺寸；`asset_version` = 产物；文件只是 `object_key` |
| 2 | 删除任务即删 DB + MinIO 对象 | **软删 30 天回收站**；原图永不物理删；仅"未归档且从未确认"允许硬删 |
| 3 | MVP 单租户、无登录（操作人写死） | **单 admin 账号登录**（Cookie 会话）；不做注册/短信/SSO；用户/角色表预留 |
| 4 | 任一字段非人工确认 → 全部生成禁用 | **`block_scope` 分级**：`generate` 拦生成、`delivery` 只拦交付；高敏字段逐项确认 |
| 5 | 成本只做"成功图"估算，`amount` 为空 | **含废弃稿/返工/视频**；`price_book` 快照 + 调用日汇率；成本页含「待定价流水」 |
| 6 | 生图工作台与制作台并列，产物都只进 job | **上下游**：工作台 = 素材工厂（产物进"未归档"）；制作台 = 交付流水线（带 SKU 上下文），显式「归入 SKU」后才进包 |

配套调整：

- 新增系统菜单：我的账号 / 日志与审计 / 成本与账单 / 系统设置（品牌、渠道、单价表）。
- 新增 `job_item`，任务粒度为"一个交付位"，支持单张重试与单张成本。
- 字段来源扩展为 `missing | ai_pending | ai_confirmed | human`，带确认人与证据。
- 品类规则以 YAML 为源、版本化（`category_rule_version`），商品绑定规则版本。

## 三、影响范围

| 维度 | 影响 |
|---|---|
| MVP 功能 | M1（商品入库、字段分级、SKU 维护）、M6（素材版本与回滚）、M7（JobItem 与成本归集）、M8（审批与软删）、M9（视频按交付位） |
| 新增模块 | 登录 / 用户（单 admin）/ 审计日志 / 成本看板 / 单价表 |
| 数据迁移 | `0003_products` → `0004_system` → `0005_billing` → `0006_assets` → `0007_jobs`，顺序不可颠倒 |
| 现有接口 | `DELETE /api/jobs` 改为软删；生成前增加服务端字段校验；素材查询改为槽位+版本 |
| 工期 | 地基（商品 + 系统 + 计费 + 素材重构 + 任务上下文）约 **+3 周**；界面改造另行估算 |
| 成本模型 | 单 SKU 成本口径改为"全部调用流水之和"，预算建议 图 ¥5 / 视频 ¥10 / 返工 ¥3，硬上限 ¥18 |

## 四、不做判断（本次不包含）

- **多用户与角色 UI**、权限矩阵界面、找回密码、管理员 MFA（V1）。
- 注册、手机验证码、微信扫码、SSO（V1/V2）。
- 对客充值、套餐、发票、自动对账（V2；本期只建表并预留字段）。
- Excel 批量导入（P1，先做模板+校验+草稿导入）。
- 跨商品复用素材（只允许同商品内引用）。
- 平台开放 API 授权 / 店铺同步 / ERP 对接。
- 平台直连发布、CDN、高可用。
