# 需求变更 · 产品结构收敛

## 一、背景

当前原型的导航是：总览 → 商品 → 项目 → 生图工作台 → 制作台 → 画布编辑器 → 任务中心 → 素材库 → 设置。

问题集中在四处：

1. **入口重复**：商品既能手动建，也能用 AI 对话录；两套字段映射与校验要同时维护。
2. **链路太长**：商品 → 制作台勾交付项 → 任务中心建 Job → 生图工作台生成 → 画布改图 → 素材库交付。真正产生价值的只有「写提示词 → 出图 → 审核」。
3. **报价挡路**：单价、预算、估算、成本页和 H1–H4 KPI 占用了主流程和首屏，但商家不在这里看报价。
4. **不能删、不能配**：商品/项目/素材只能新增；模板库只有一句规划（F02），没有对象和 CRUD。

本次把产品收敛成：**对话录商品 → 基于商品建多个项目 → 项目画布直接生图 → 结果自动进素材库 → 审核交付**，删除可恢复，模板可维护。

## 二、变更点

| # | 原内容 | 新内容 |
|---|---|---|
| 1 | 商品有「新建商品」表单 + 「AI 录入」聊天两个入口 | **聊天是唯一创建入口**；模型或渠道不可用时允许先存**空草稿**再逐项手填；确认入库仍需人工 |
| 2 | 一个商品一个项目，项目走「规划 → 人工确认 → 执行」 | **同一商品可建多个项目**；项目 = 一次生产（画布 + 模板 + 提示词），互不影响 |
| 3 | 项目创建后要先规划、确认清单 | 建项目即铺**默认流程**：`source → generate → human_review → deliver`，按 SKU 各一条；可增删节点 |
| 4 | 独立「生图工作台」页面负责提示词与单张生成 | **合并进项目画布**：选中 `generate` 节点在右侧检查器填提示词/模型/尺寸/模板，可单节点试跑 |
| 5 | 制作台勾交付项、任务中心管 Job | **两页下线**；执行粒度**只能按 SKU 单独跑**，没有「全部 SKU 一键跑」；人工确认节点会暂停 |
| 6 | 画布固定六类节点（source/generate/refine/quality_check/human_review/deliver） | **参数化节点 + 白名单处理节点**：生成/精修可配模型、提示词、尺寸、模板；处理节点只允许裁剪、拼接、加水印、换字；**不执行任意代码** |
| 7 | 提示词属于生图工作台的一次请求 | **每个 generate/refine 节点自带提示词与参数**，随项目保存 |
| 8 | 版式模板只有规划，无对象 | 新增**版式模板**：尺寸、主体占比、接地阴影、文字槽位、Logo 位；表单编辑 + 实时预览；**节点级选用** |
| 9 | 模板改动会立即影响所有项目 | 项目建时**快照模板**，改模板只影响新项目/新节点 |
| 10 | 内置模板不可维护 | 内置 3–5 个，**可删、可一键恢复**；自建模板可增删改 |
| 11 | 素材只在生成后手动留档 | 生成成功**自动写入素材库并生成版本**；审核链保留（待确认 → 已确认/已驳回，新确认让旧确认过期） |
| 12 | 独立「画布编辑器」页做改价格/改错字 | 收进**素材库**：打开某版本进入编辑器，保存生成新版本 |
| 13 | 商品/项目/素材只能新增，模板不能删 | 四类对象都支持删除：**软删 30 天 + 回收站**；删商品级联隐藏其项目与素材；原图永不物理删除 |
| 14 | 回收站无入口 | **设置 → 回收站**统一恢复/彻底删除，支持类型筛选 |
| 15 | 前台有单价、预算、估算、成本页、H1–H4 KPI | **全部删除**；`provider_call` 计费流水继续落库（红线 #5），但**后台也不做账单页面**，需要时查库；`price_book` 表保留 |
| 16 | 视频是制作单交付项、有独立步骤 | **本期入口全部隐藏**，模型位保留；M9 文档仍在，不进本期验收 |

### 关键边界

- 商品事实只来自商家资料，AI 只整理、不补全；空草稿也不预填任何事实。
- 生成成功即入库，但「可交付」仍由 `human_review` / `deliver` 决定；未审核的版本不能导出。
- 处理节点是白名单原子操作，不允许上传脚本、不允许任意网络访问。
- 模板快照写进节点配置，不在运行时重新读模板。
- 删除只做软删；任何接口都不提供物理删除（原图尤其）。
- 前台不再出现金额；调用次数与产出张数可以提示。

## 三、影响范围

### 页面

| 保留 | 下线 |
|---|---|
| 工作台总览（无 KPI，只留入口 + 最近项目） | 制作台 |
| 商品（只剩聊天录入） | 任务中心 |
| 项目（画布工作区） | 生图工作台 |
| 素材库（版本/交付/模板/改图） | 画布编辑器（并入素材库） |
| 设置（含回收站） | 首屏 H1–H4 KPI |

### 数据模型

| 变更 | 说明 |
|---|---|
| 新增 `layout_template` | 版式模板；`builtin` + `builtin_key` 支持恢复；`deleted_at` 软删 |
| `product.deleted_at` | 商品软删；级联把引用它的项目置软删 |
| `project.deleted_at` | 项目软删 |
| `project.canvas` | 项目级画布（节点含类型、参数、提示词、模板快照） |
| 节点参数 | `model_key / prompt / size / template_snapshot / operation`（处理节点） |
| 模板快照 | 建节点时复制模板字段，不引用模板行 |
| 素材版本 | 生成成功自动建 asset + version；本次先复用现有 Asset，版本表随 TD-004 `0006` 落地 |
| 执行记录 | 每条 SKU 执行一条 run；`provider_call` 不变 |

### 接口

- 新增 `GET/POST/PATCH/DELETE /api/templates`、`POST /api/templates/{id}/restore`、`POST /api/templates/restore-builtins`。
- 新增 `DELETE /api/products/{id}`、`POST /api/products/{id}/restore`。
- 新增 `DELETE /api/projects/{id}`、`POST /api/projects/{id}/restore`。
- 新增 `GET /api/trash?type=product|project|template`。
- 项目画布：`PUT /api/projects/{id}/canvas`、`POST /api/projects/{id}/runs`（按 SKU）。
- 下线/不再扩展：报价、预算、成本、KPI 相关接口与页面。

### 计费与验收

- `provider_call` 继续每次调用落一行；金额可为空（未定价），不影响调用与审计。
- Go/No-Go（一次通过率、单 SKU 成本、交付时长、上架意愿）改为**人工实测并记 `PHASE.md`**，产品内不出面板。

## 四、不做判断（本次不包含）

- 不做视频生成接入；只隐藏入口。
- 不做任意脚本沙箱；处理节点仅白名单原子操作。
- 不做 Excel 批量导入（仍是 P1）。
- 不做品牌资产（颜色、字体管理）；模板只做版式，Logo 只是槽位字段。
- 不做「全部 SKU 一键跑」。
- 不做多用户与权限矩阵；仍为单管理员。
- 不做物理删除/清空回收站以外的批量清理；原图永不删。
- 不做后台账单页面；查账靠 SQL/运维。
- 不做模板可视化拖拽编辑器；本期表单 + 预览。

## 五、验收标准

1. 商品页没有手动新建入口；只能通过聊天创建，模型不可用时可存空草稿并手填。
2. 同一商品可创建多个项目；新项目打开即有默认 DAG（按 SKU 各一条）。
3. 画布可增删节点、改参数；生成节点带提示词与模板；处理节点只出现白名单操作。
4. 只能按 SKU 启动执行；人工确认节点暂停等待操作；生成前提示调用次数与产出张数。
5. 生成成功后素材库出现新版本；审核链可确认/驳回，旧确认自动过期。
6. 模板可新增、编辑、删除、恢复内置；改模板不影响已建项目；节点可选用模板。
7. 商品/项目/素材/模板删除后进入设置 → 回收站；可恢复；删商品级联其项目与素材。
8. 全站无报价、预算、估算、成本页、KPI；`provider_call` 仍有记录。
9. 视频入口在项目、素材、画布中均不出现。
10. 制作台、任务中心、生图工作台、画布编辑器四个旧入口不可达。

## 六、待确认与后续

1. `provider_call` 无界面后的查账方式（SQL 模板 / 运维脚本）。
2. 回收站 30 天自动清理任务的执行频率与失败告警。
3. 现有 `project-ui` 的「规划/确认」数据：迁移还是清空（原型可直接重置）。
4. 模板字段最终清单与内置模板内容（先按尺寸/占比/阴影/文字槽位/Logo 位）。
5. 处理节点所需图像库与部署依赖（裁剪、拼接、水印、换字）。
